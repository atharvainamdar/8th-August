# Specialist Pilot Protocol

Lumi is an educational practice tutor. It is not a clinical assessment or therapy product.

## Goal

Measure whether daily adaptive practice improves engagement and skill mastery for autistic learners ages 7–10 in reading, writing, and arithmetic.

## Design

- Duration: 2 weeks
- Frequency: 4–5 sessions/week
- Length: 12–15 minutes/session
- Devices: tablet preferred
- Setup: sensory mode + interest pack + placement

## Measures

1. In-app mastery means (reading/writing/math)
2. Scaffold fade (guided → independent)
3. Session completion and adaptations count
4. Qualitative notes from educator/parent (homework conflict, child initiation)

## Export

Adult view → Export JSON after day 0, day 7, day 14.
