# Curriculum Overview

Skill graph lives in `content/skills.json` (115 nodes across reading, writing, math).

## Reading

- Phonemic awareness → letter sounds → CVC → blends/digraphs → silent e → vowel teams → r-controlled → multisyllable
- High-frequency irregulars
- Fluency + literal/inferential comprehension

## Writing

- Lower/uppercase letter formation
- Spelling CCC tied to phonics
- Sentence frames → expand → POW short response
- Speak-to-write alternate pathway

## Arithmetic

- Number sense to 10/20/100
- Place value
- Add/sub within 20 and 100
- Multiplication/division concepts
- Fact fluency
- Schema word problems: add-to, take-from, compare, equal groups
